SYSTEM SPECIFICATION AND USER GUIDE
About the project: A complete low-level development and emulation environment for the CHIP-8 architecture. Its core is a high-performance CPU interpreter and virtual file system (VFS), written in C and compiled by Emscripten to WebAssembly (WASM). This enables fast instruction execution at 60 FPS and direct memory access through a JavaScript `Uint8ClampedArray`.
Display and Memory: The left panel contains the original two-color 64x32 display with pixel-accurate rendering. Beside it, a live Memory Map visualizes all 4096 bytes of processor RAM. Hover over it to inspect memory addresses and their current values in real time.
Developer Tools (IDE): The lower panel combines an interactive debugger for monitoring registers V0–VF, the program counter (PC), and timers, along with an SPD Stack for tracking stack values.
Integrated Assembler: The editor on the right provides syntax highlighting for CHIP-8 mnemonics (for example, `LD V0, 0xFF` and `CLS`). Compile code in the browser with Compile & Run and save source files in `.asm` format.
Virtual Disk (FAT/VFS): The project emulates 1 MB of persistent storage. Compiled binaries and saved assembler source are stored in a virtual file table synchronized with the browser's IndexedDB. Run or delete files directly from the list.
Load a game: Drag a `.ch8` ROM file into the LOAD ROM area below, or click it to choose a file and load it into the emulator.
