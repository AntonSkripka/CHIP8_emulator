CHIP-8 VIRTUAL MACHINE

A COMPLETE LOW-LEVEL DEVELOPMENT AND EMULATION ENVIRONMENT FOR THE CHIP-8 ARCHITECTURE. THE CPU INTERPRETER AND VIRTUAL FILE SYSTEM ARE WRITTEN IN C AND COMPILED TO WEBASSEMBLY FOR FAST IN-BROWSER EXECUTION.

[ DISPLAY AND MEMORY ]

THE ORIGINAL TWO-COLOR 64 × 32 DISPLAY RENDERS CHIP-8 GRAPHICS. DEVELOPER MODE ALSO INCLUDES A LIVE MEMORY MAP OF ALL 4096 BYTES OF RAM. POINT AT A CELL TO INSPECT ITS ADDRESS AND VALUE.

[ DEVELOPER TOOLS ]

MONITOR THE V0–VF REGISTERS, PROGRAM COUNTER, INDEX REGISTER, STACK POINTER, TIMERS, AND CALL STACK WHILE A ROM RUNS.

[ INTEGRATED ASSEMBLER ]

WRITE CHIP-8 MNEMONICS SUCH AS LD V0, 0xFF OR CLS, THEN COMPILE AND RUN THEM IN THE BROWSER. ASSEMBLY SOURCE FILES CAN BE SAVED TO THE VIRTUAL DISK.

[ VIRTUAL DISK / FAT VFS ]

THE EMULATOR PROVIDES 1 MB OF VIRTUAL STORAGE. ROMS AND ASSEMBLY FILES ARE STORED IN THE VIRTUAL FILE SYSTEM AND SYNCHRONIZED WITH BROWSER INDEXEDDB.

LOAD A GAME: DROP A .CH8 ROM ON THE LOAD ROM PANEL OR SELECT A FILE.
USER MODE: PLAY ROMS WITH A CLEAN DISPLAY.
DEVELOPER MODE: ACCESS THE ASSEMBLER AND LIVE DIAGNOSTIC TOOLS.
